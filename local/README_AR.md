# تشغيل ERP داخل الشبكة المحلية

هذه الحزمة تشغّل تطبيق ERP على **الجهاز الرئيسي في المحل** ليكون متاحاً لأجهزة الكاشير والهواتف المتصلة بالشبكة نفسها. لا تفتح منفذ التطبيق للإنترنت العام.

## المتطلبات

يحتاج الجهاز الرئيسي إلى Node.js 22 أو أحدث، وpnpm، وMySQL 8 أو TiDB متوافق. يجب أن يكون لكل جهاز كاشير متصفح حديث وأن يتصل بالسويتش أو Wi‑Fi المحلي نفسه.

## ربط Supabase (PostgreSQL)

المشروع الحالي مبني على MySQL، لذلك لا يكفي وضع مفتاح Supabase لتشغيل بيانات ERP عليه: يلزم تحويل طبقة Drizzle والترحيلات من MySQL إلى PostgreSQL أولاً. أُضيف ملف `local/supabase.config.template.txt` ليحفظ إعدادات الربط بأمان، ولا تضع مفاتيح Supabase في `client/` أو في أي متغير يبدأ بـ`VITE_`.

ستحتاج أيضاً إلى **كلمة مرور قاعدة البيانات** أو رابط الاتصال الكامل من **Dashboard > Connect > ORMs > Node.js**؛ مفتاح الخدمة ليس بديلاً عنها. بعد توفيره يمكن تنفيذ ترحيل PostgreSQL وإنشاء الجداول في مشروع Supabase.

## الإعداد الأولي

استخدم `local/config.template.txt` كمرجع واكتب القيم يدوياً في `.env` في جذر المشروع. أنشئ قاعدة MySQL ومستخدماً محدود الصلاحيات، ثم ضع رابطها في `DATABASE_URL`. أنشئ قيمة عشوائية طويلة لـ`JWT_SECRET`. لا تضع أي كلمة مرور أو ملف `.env` في Git أو ترسله عبر واتساب.

## التشغيل

في Linux أو macOS شغّل:

```bash
bash local/run-local.sh
```

وفي Windows شغّل `local\start-erp.bat` من موجّه الأوامر. سيقوم المسار بتثبيت الاعتمادات وترحيل قاعدة البيانات وبناء التطبيق ثم تشغيله على جميع واجهات الشبكة (`0.0.0.0`).

## ربط الأجهزة

افتح صفحة **الشبكة والربط المحلي** من الشريط الجانبي في ERP. تظهر فيها عناوين LAN للجهاز الرئيسي مثل `http://192.168.1.20:3000`. افتح العنوان نفسه على أجهزة الكاشير. إذا لم يفتح، اسمح للمنفذ 3000 في جدار الحماية المحلي، وتأكد أن الأجهزة على الشبكة نفسها.

> يتيح هذا المسار تشغيل الخادم والبيانات داخل الشبكة المحلية. أما العمل دون أي اتصال بالشبكة أو الإنترنت فيتطلب مرحلة لاحقة لتطبيق PWA مع تخزين ومزامنة محليين؛ لا يجوز ادعاء أن النسخة الحالية تعمل دون اتصال قبل إضافة تلك المرحلة واختبارها.
